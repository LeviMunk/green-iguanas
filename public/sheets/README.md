# Approved D&D Beyond character PDFs

Place player-approved PDF exports here as `<character-id>.pdf`. All files in this directory are **public** on GitHub Pages. Character profiles currently show placeholders and no PDF is included.

Once an approved PDF is present, set the matching `sheetPdf` value in `src/data/campaign.ts` (for example `sheets/bobby-kills.pdf`).

See `docs/sheets-and-game-log.md` for the complete procedure.
